# ElainaAP

- **作者**：伊蕾娜
- **版本**：`1.1.0`
- **声明**：本工具完全免费，仅供个人学习与研究交流。

---

## 功能列表

- **战斗**：无敌 / 多段攻击 / 强制破防 / 必定暴击 / 技能无冷却 / 无限能量
- **移动**：自由移动 / 移速倍率 / 无限冲刺
- **视觉**：解锁帧率 / 实时帧数显示 / ESP / 去虚化 / 视野 FOV / 隐藏 UI / 自定义 UID
- **皮肤**：英雄本地换装 / 主角装扮全解锁 / 宠物本地换装 / 自动长期保存与恢复
- **剧情**：解锁跳过 / 跳过动画 / 剧情倍速 / 自动播放 / 自动选择 / 快捷跳过
- **传送**：坐标传送 / 传送点管理 / 任务传送 / 地图指针传送 / 大世界收集点传送
- **世界**：全局倍速 / 目标不主动攻击 / 自动拾取 / 自动开宝箱 / 自动挖矿 / 家园自动收获 / 自动解密
- **快捷键与界面**：主键盘、数字小键盘与鼠标侧键绑定 / 界面缩放 / 配置保存与读取

---

## 使用说明

1. 管理员运行 `Elaina-AP.exe`。
2. 从启动器启动游戏。
3. 默认按 `Insert` 呼出或隐藏菜单（可在设置中修改）。
